# ppp-proxy-deno

## `main.js` — CORS-прокси на Deno

Пробрасывает запросы на произвольный хост/порт, заданный заголовками
`X-Host`/`X-Port`, и проставляет CORS-заголовки в ответе. Разворачивается,
например, на [Deno Deploy](https://deno.com/deploy).

## `extension/` — быстрые заявки для Т-Банк Инвестиции

Браузерное расширение с минималистичной панелью поверх
`tbank.ru/terminal`: тикер, сумма, «Купить»/«Продать» — заявка ставится
по лучшему биду/аску через T-Invest API. Подробности и установка — в
[`extension/README.md`](extension/README.md).
