# Быстрые заявки для Т-Банк Инвестиции

Минималистичное браузерное расширение (Manifest V3), которое добавляет
плавающую панель поверх `https://www.tbank.ru/terminal/`: тикер, сумма и
две кнопки. «Купить» ставит лимитную заявку по текущему лучшему биду,
«Продать» — по текущему лучшему аску. Заявка уходит напрямую в
[T-Invest API](https://developer.tbank.ru/invest/intro/intro) из фонового
скрипта расширения — без прокси и без лишних кликов в интерфейсе.

## Установка

1. Откройте `chrome://extensions` (или `edge://extensions`).
2. Включите «Режим разработчика».
3. «Загрузить распакованное расширение» → выберите папку `extension/`.
4. Кликните по иконке расширения — откроются настройки.

## Настройка

- **Токен T-Invest API** — создаётся в личном кабинете Т-Инвестиций
  (Настройки → Токены API). Для реальной торговли нужен токен с полным
  доступом (не read-only).
- **ID счёта** — необязательно; если не указан, используется первый
  открытый брокерский счёт.
- **Источник котировок**:
  - *MOEX ISS / Алгопак* (по умолчанию) — котировки берутся из стакана
    MOEX ISS. Требует логин/пароль
    [MOEX Passport](https://passport.moex.com/) с активной подпиской на
    Алгопак — без них запросы к стакану будут падать с ошибкой
    авторизации.
  - *T-Invest MarketData* — лучший бид/аск берётся прямо из вашего
    брокерского подключения, без дополнительной настройки. Используйте
    как запасной вариант, если подписки на Алгопак нет.
- **CORS-прокси** — расширение обращается к API напрямую (фоновый
  service worker с `host_permissions` не подчиняется CORS), прокси не
  нужен. Тумблер оставлен на случай сетевых ограничений — тогда можно
  указать URL своего развёрнутого `ppp-proxy-deno` (см. корень
  репозитория).

## Как считается количество лотов

Сумма, введённая в поле «Сумма, ₽», делится на цену лота (цена лучшего
бид/аска × размер лота инструмента), результат округляется вниз, минимум
1 лот. Если введённой суммы не хватает на 1 лот, заявка всё равно уйдёт
на 1 лот — панель покажет фактическую цену и количество после отправки.

## Ограничения и оговорки

- Это лимитная заявка по цене топа стакана на момент клика, а не
  гарантированное исполнение — котировки могут измениться на долю
  секунды между запросом стакана и постановкой заявки (обычная гонка
  для любого HFT/скальперского инструмента).
- Названия методов и полей T-Invest API соответствуют документации на
  момент написания кода. API меняется — при ошибках сверьтесь с
  актуальной документацией на developer.tbank.ru.
- Расширение хранит токен и учётные данные MOEX в `chrome.storage.sync`
  (синхронизируется через аккаунт браузера). Если это нежелательно,
  замените на `chrome.storage.local` в `background.js`/`options.js`.
